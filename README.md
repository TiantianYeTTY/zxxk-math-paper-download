# zxxk-math-paper-download

> 面向学科网（zxxk.com）的 **初中数学试卷自动化下载技能**（Agent Skill）。
>
> 从环境自检、浏览器自动化下载，到限速防风控、**教材版本三层核验**（确保沪教版（五四制）新教材）、ZIP 乱码修复，再到交付清单生成——一条龙完成，全程不改动试卷内容。
>

## ✨ 这是什么

`zxxk-math-paper-download` 是一个 Agent Skill（智能体技能包），把一次完整的学科网试卷批量下载任务沉淀为可复用的工作流与踩坑经验。它解决的问题非常具体：

- 学科网对批量下载有严格风控：**每天约 20-25 份**的上限，超了要么弹微信扫码验证墙、要么静默限速——快速连续下载必然翻车；
- **标签页在后台时，点击下载会被静默忽略**（无弹窗、无下载、无报错），极易误诊为"资源损坏"或"账号异常"；
- 期中卷详情页**不显示教材版本字段**，标题也不写新旧教材——2023-2024 及更早的卷子全是旧教材时期出品，仅凭标题筛选必然混入旧教材卷；
- 试卷 ZIP 内文件名是 GBK 编码，直接解压全是乱码；
- 用户对"教材准确、每份含题目+解析、来源唯一、限速下载"有硬性验收标准，任何一条不达标都会返工。

本技能将整个流程标准化：**环境自检 → 单份下载（70-80 秒限速）→ 新教材三层核验 → 按年级归档 → 交付清单生成**，并对过程中 12 个坑位给出了根因分析与标准解法。已在真实任务中完成 **44 份试卷**（六/七/八/九年级沪教版（五四制）新教材上海期中卷）的下载与全量核验。

## 🎯 使用场景

当你的任务符合以下画像时，即可使用本技能：

| 要素 | 说明 |
|---|---|
| 来源站点 | 学科网 zxxk.com（唯一来源，不接受第三方） |
| 教材 | 沪教版（五四制）新教材（上海；方法论可迁移至其他教材版本核验） |
| 试卷类型 | 期中/期末/月考等成套试卷，优先"精品解析"资源（原卷版+解析版双 docx） |
| 数量目标 | 每年级 10~15 份 |
| 账号 | 学校服务账号（网校通权益，付费卷权益内免费；真实扣储值需用户逐笔确认） |
| 用户诉求 | "仅学科网来源、每份含题目+解析、限速下载（每份间隔≥1分钟）、不做任何改动、交付原链接清单供逐条复查" |

典型触发指令示例：

> 帮我下载六年级到九年级上学期的沪教版五四制上海期中卷试卷。每下载一份必须等待1分钟，禁止批量快速下载。所有试卷必须是沪教版（五四制）新教材，每份都要包含题目和解析，全部来源于学科网，下载后给我原链接清单。

## 🚀 使用方法（工作流概览）

技能按以下阶段自动执行，完整细节与全部命令见 [SKILL.md](SKILL.md)：

| 阶段 | 内容 | 关键点 |
|---|---|---|
| 1. 环境自检 | CDP 代理（localhost:3456）连通性、Chrome 远程调试（9222）、登录态确认 | 断连时 `pkill cdp-proxy` + 重启 Chrome 恢复；会话数小时过期需重新登录 |
| 2. 置前标签页 | `document.visibilityState === "visible"` 强制校验 | **最大坑位**：后台标签页点下载被静默忽略，先查可见性再怀疑别的 |
| 3. 试卷挑选 | 学科网筛选 + 学年审核 | 按新教材滚动时间线过滤（六七=2024起/八=2025起/九=2026起） |
| 4. 单份下载 | 详情页 → 真实鼠标点击下载按钮 → 确认"网校通权益·免费" → 等待落盘 | 每份强制间隔 70-80 秒；`clickAt` 真实鼠标事件而非 JS click |
| 5. 解压归档 | GBK 文件名还原解压 → 按年级文件夹归档 | 解压后核对文件夹名与资源标题（防错包） |
| 6. 教材核验 | 三层核验：学年审核 → 内容级章节验证 → 同步树 ID 比对 | 新教材独有章节命中；不合格移入隔离文件夹 |
| 7. 交付 | 《下载清单与说明.md》+《试卷原链接清单.md》 | 断点续传日志 + 原链接清单供逐条复查 |

### 输入 / 产出

```
输入                                   产出
──────────────────────────           ─────────────────────────────
学科网账号（Chrome 已登录）      ───▶  六/七/八/九年级/ 试卷文件夹（精品解析套装）
试卷筛选清单（年级/数量/学年）   ───▶  下载清单与说明.md（数量+核验结论+剔除记录）

                                  ───▶  download_log.json（断点续传进度）
```

## 🔧 环境依赖

- **macOS**（工作流按 macOS 打磨）
- **Google Chrome** + 远程调试端口 9222（`chrome://inspect/#remote-debugging` 勾选允许）
- **WorkBuddy web-access 技能**（CDP 代理 localhost:3456，提供 /new /eval /clickAt /screenshot 等端点）
- **Node.js**（运行 batch_download.js）与 **Python 3**（运行解压脚本）
- 学科网账号：学校服务用户/网校通权益（普通账号只能下免费资源）
- 微信（触发风控验证墙时需人工扫码，微信手机号须与账号绑定手机一致）

## ⚠️ 重要说明

1. **教材版本核验是硬约束**：期中卷详情页无教材字段，必须做三层核验（学年审核→内容级章节验证→同步树 ID 比对），仅凭标题筛选必然混入旧教材卷。
2. **限速是账号安全的底线**：约 20-25 份/天；每份间隔 ≥60 秒；触发风控（扫码墙/静默限速）当日停止，隔夜恢复。
3. **标签页前台是下载前提**：后台标签页的下载点击被静默忽略，所有"空失败"先查 `visibilityState`。
4. **真实扣费需用户确认**：确认框含"储值/余额/支付方式"字样时，列出价格请用户逐笔确认，绝不擅自扣费；"网校通权益 | 免费"可直接下载。
5. **不删除任何文件**：不合格资源移入 `_旧教材已剔除/`、`_待核验/` 隔离文件夹（用户可能要求恢复或自行复核）。
6. **内容零改动**：试卷仅下载与解压归档，不编辑、不重命名试卷内部文件。

## 🐛 已知踩坑点（节选）

references/pitfalls.md 中记录了完整的 12 条「现象 → 根因 → 修复」，包括：

- Chrome 标签页在后台时，学科网下载 JS 检测 `visibilityState` 直接静默忽略点击（曾误诊 12 份正常资源为"服务器损坏"）；
- 风控验证墙是跨域 iframe（`downloadnew.zxxk.com`，480×399），脚本读不到内容，只能人工扫码；静默限速形态下连弹窗都没有；
- 期中卷详情页无教材版本字段，"沪教版（五四制）"名称同时覆盖新旧版——需按官方学年时间线+新教材独有章节+同步树 ID 三层核验；
- 后台任务沙箱偶发拒绝文件写入（`CODEBUDDY_BROKER_DENY`），进度日志丢失会导致重复下载；对账以文件系统为准；
- 页面 `<a>` 可能没有 href，`getAttribute("href").match()` 直接抛 TypeError（采集资源 ID 必须先判空）；
- 学科网 ZIP 内文件名 GBK 编码，需 cp437→gbk 还原；Chrome 对重名下载自动加时间戳后缀；
- ……（完整清单见 references/pitfalls.md）
