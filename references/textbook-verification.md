# 沪教版（五四制）新教材核验方法论

目标：确认每份试卷基于**新教材沪教版（五四制）**编写（用户定义的验收标准，术语与学科网站内教材名一字不差）。

## 背景知识

- 上海初中为五四学制（六/七/八/九年级），数学教材体系即"沪教版（五四制）"（站内教材树原名，2024 课标修订版）。
- **新教材按学年分批启用**（依据沪教委基〔2024〕19 号，三年推进）：

| 学年 | 数学新教材覆盖 |
|------|----------------|
| 2024 学年（2024年9月） | 六、七年级 |
| 2025 学年（2025年9月） | 六、七、八年级 |
| 2026 学年（2026年9月） | 九年级（首次） |

- 关键推论：**2023-2024 及更早的所有卷子都是旧教材**；2024-2025 的八/九年级卷也是旧教材；2025-2026 的九年级在校生仍在用旧教材。
- 新教材九上首个期中真题最早出现于 2026 年秋；此前九年级新教材材料只有模拟/仿真卷。

## 新旧教材章节对照（内容级验证的判据）

| 年级上册 | 新教材章节（命中即合格） | 旧教材标记（命中即剔除） |
|----------|--------------------------|--------------------------|
| 六年级 | **有理数**（第1章）、简单的代数式、一元一次方程、线段与角 | 数的整除/比和比例体系为主、无"有理数" |
| 七年级 | **整式的加减+整式的乘除+因式分解**（三章体系）、平行线 | 整式仅一章、无因式分解章 |
| 八年级 | **实数、二次根式、一元二次方程**、全等三角形 | 相似三角形提前、无实数章 |
| 九年级 | 相似三角形（第28章）、**三角初步**（第29章）、**投影与视图**（第30章）、二次函数（第27章） | "锐角的三角比"、"第24~25章"旧编号体系 |

注意："相似三角形"新旧教材都有，单独出现不能判旧；"三角初步/投影与视图"或"第27~30章"编号才是新教材判据。"锐角的三角比"是旧教材独有。

## 三层核验流程

### 第一层：学年审核（快速过滤）

从标题提取学年起始年（如"2025-2026"→2025，"2025学年"→2025），对照门槛：
```
六年级/七年级：start >= 2024
八年级：start >= 2025
九年级：start >= 2026（模拟卷按标注学年）
```
不达标直接移入 `_旧教材已剔除/`，记录原因。

### 第二层：内容级验证（决定性证据）

解压后逐份提取 docx 纯文本（zipfile 读 word/document.xml + 去标签），验证命中年级新教材章节标记。要点：

```python
import zipfile, re
def docx_text(path):
    z = zipfile.ZipFile(path)
    xml = z.read("word/document.xml").decode("utf-8", "ignore")
    return re.sub(r"<[^>]+>", "", xml)
```

- 每套双文件资源检查原卷/解析任一命中即可；全部文件循环取最佳。
- 单文件 docx 同时验证含"答案/解析"字样（满足"题目+解析"要求）。
- PDF 无法用此法时渲染首页人工目检（sips 转 PNG 后读图）：确认标题为"预备年级/六年级+期中"且内容为新教材章节。
- 无命中标记的卷子逐个人工复核（可能是图片版公式），不能自动判死。

### 第三层：同步树 ID 比对（站点侧官方佐证，可选加强）

「教材同步 > 沪教版（五四制）> X年级上册 > 期中」列表里的资源 = 站点自身标注为该教材的资源。

- 各年级上册教材编号（b 编号）：**六上=b6790、七上=b6800、八上=b7421、九上=b8168**
- 期中列表 URL：`https://sx.zxxk.com/m/books-b{ID}-sce420105/page-N.html`
- 爬取方法：按最新排序，从第 1 页向下翻，每页采集资源 ID（注意 null href 保护）；列表分页上限 100 页，资源量大时（八上 9030 个）用二分法按资源 ID 定位目标区间再局部爬取
- 实测命中率：六上 491 资源中 13/14、七上 7951 中 13/15、八上 9030 中 13/13、九上 2/2
- **未命中 ≠ 教材错误**：站点不会把所有资源都归入同步树（约 10-20% 未入树），未命中的卷子以第二层内容级验证为准

## 已知的特殊情形

1. **"沪教版（五四制）"名称覆盖新旧版**：站内教材树的名字就是"沪教版（五四制）"（面包屑实证：教材同步 > 沪教版（五四制）> 六年级上册），但树里收录的是新教材资源。旧教材时期资源大多未入树或挂在其他名目下。
2. **九年级新教材卷稀缺**：2026 学年前不存在新教材九年级期中真题，只有模拟/仿真卷；若用户要求九年级严格新教材真题，需说明此客观限制。
3. **错包资源**：极少数资源 ZIP 内容与标题不符（下载后解压核对文件夹名），发现即隔离到 `_待核验/`。
4. **直接从同步树选卷**（最稳方案）：如果用户允许，直接在「教材同步 > 沪教版（五四制）> X年级上册 > 期中」列表里挑卷下载，天然保证教材正确——但该列表不含全部期中卷，且部分资源是讲义/专题而非整卷，需人工甄别。
