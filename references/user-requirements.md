# 用户要求与雷区清单（历史 Prompt 沉淀，任务开始前必读）

以下条目全部来自用户的原话要求与不满反馈，违反任何一条都会导致返工。

## 硬性要求（用户多次强调）

1. **来源唯一**：所有试卷务必来源于学科网 https://www.zxxk.com ，"不允许从其他第三方搜索信息，能且仅能从该网站下载"。
2. **教材准确**："所有试卷的教材来源必须是'沪教版（五四制）'，教材名就叫'沪教版（五四制）'"（站内名一字不差）。旧教材时期的卷子不算——用户明确指出 2023-2024 八年级卷不是沪教版五四制新教材。
3. **限速下载**："每下载一份试卷需要必须等待1分钟，禁止通过脚本一次性批量下载大量试卷；之前触发风控就是这个原因。不允许再一次性下载大量试卷，每次下载完必须等待。"
4. **每份含题目和解析**："每份试卷都需要包含题目和解析"——精品解析资源（原卷版+解析版）是首选；纯原卷版、图片版无答案的资源用户不接受。
5. **不改动**："不允许对下载的卷子做任何改动，仅下载。"
6. **数量目标**："每个年级尽可能收集更多试卷，10～15份为益。"
7. **付费卷可下**："我的账号是可以下载付费试卷的，务必下载高质量试卷。"——网校通权益内的"免费"（原价划线）资源正常下载。
8. **需要链接清单**：用户要逐条复查下载质量，必须交付全部试卷的原链接清单（zxxk.com/soft/{ID}.html）。

## 扣费红线

- 显示需扣**储值余额**的资源（如"原价：2.00元 | 支付方式：储值"）：**必须先列出价格请用户确认**，未确认绝不点击。已发生案例：杨浦区卷 ¥2 储值，用户最终明确"不要下载"。
- 网校通权益覆盖的（确认框显示"网校通权益 | 免费"）：可直接下载，这是账号权益范围内的。
- 判断依据：弹窗文案。含"储值/余额/支付方式"字样 = 真实扣费；含"网校通权益 | 免费" = 权益覆盖。

## 资源取舍标准（用户逐条确认过）

**必须剔除**：
- 旧教材时期的卷子（按新教材启用时间线判定）
- 重复资源（同校同学年的原卷版与精品解析版只留精品解析版）
- 无答案/无解析的版本（原卷版单文件、图片版）
- 不是期中卷的材料（如同步知识清单——除非用户明确要）
- 外地版本、其他教材体系

**用户明确认可**：
- 沪教版（五四制）上海专用期中模拟/仿真卷可以保留（九年级真题稀缺时的替代品）
- 精品解析资源 = 原卷版+解析版双 docx，满足"题目+解析"要求

## 沟通与汇报要求

1. **诚实透明**：用户会追问"你当时到底如何判断的？还是根本没做判断？"——必须如实交代验证方法与局限，过度声明（"教材版本全部核验通过"但实际没验 edition）会被识破并引发信任问题。
2. **不满意的历史点**：
   - 曾以为"付费=不能下载"而跳过精品解析资源（用户纠正：账号有网校通权益）→ 之后要实测确认权益覆盖再决定
   - 曾下载旧教材卷未察觉（用户指出同凯 2023-2024）→ 补做了三层核验
   - 曾说"资源服务器损坏"，实际是标签页后台问题（用户让停止操作并质疑）→ 先查 visibilityState
   - 曾说"触发扫码验证"，用户浏览时看不到 → 扫码只在点击下载瞬间出现，且有静默形态
3. **解释要通俗**：用户对"八九年级什么情况"表示没看懂过——用表格+分年级说明，避免术语堆砌。
4. **用户澄清要及时采信**：如"错包是我并行任务导致的，不是你的问题"、"普陀 PDF 是我亲自删除的"——立即更正记录，不要坚持自己的旧结论。
5. **被质疑时先自省再辩护**：用户问"是在撒谎咯？"——如实承认核验维度不完整，比辩解更有效。
